# Notion版 夏休み学習計画 2026

このZIPは、Notionに取り込むための学習計画セットです。

## ファイル一覧

- `00_ダッシュボード.md`：トップページ用
- `01_日別プラン.csv`：毎日更新するメインDB
- `02_週間目標.csv`：週末レビュー用DB
- `03_科目ロードマップ.csv`：科目別の到達目標DB
- `04_TOEIC対策.csv`：TOEIC対策DB
- `05_時間割テンプレート.md`：時間割の参照ページ
- `Notion_取り込み手順.md`：Notionでの設定方法

## まず使うもの

1. `00_ダッシュボード.md`
2. `01_日別プラン.csv`

この2つをNotionに取り込めば、日々の運用を始められます。
